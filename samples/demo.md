Drop this file into `annotator.html` to try it out. Every section below has
something worth marking.

## 1 · Duplicate

The purpose of this feature is to improve the user experience. By streamlining
the interaction flow, we can effectively improve the user experience, so that the
overall experience of the product is improved.

> Try: select the last two sentences, tag them **Duplicate**, and submit without
> writing anything.

In light of the foregoing and pursuant to a holistic assessment of the
aforementioned factors, the proposal possesses a robust foundation for
operational implementation.

> Try: select the whole sentence, tag it **Tone**, write "say it like a person".

Confucius himself; it runs to twenty chapters and about fifteen thousand words.

> Try: select "written by Confucius himself" and tag it **Fact**.

4. Click `?` to see where notes are stored
5. `F8` / `Shift+F8` steps through your notes
